# OrbitDrift

OrbitAware technology utilizes DriftSmart algorithms for real-time-data-processing and auto-scaling-capabilities on the DriftEngine within OrbitPlatform infrastructure.

OrbitDrift is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/OrbitDrift.git`
2. `cd OrbitDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

OrbitDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
